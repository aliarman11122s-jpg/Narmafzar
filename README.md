# Bbitcoin Android — Demo

This is an educational local proof-of-work demo. BBC rewards are not real cryptocurrency and cannot be transferred or traded. The app does not connect to a public blockchain.

## Build APK on GitHub
1. Upload the *contents* of this folder to the root of a GitHub repository, including the hidden `.github` directory.
2. Commit to the `main` branch.
3. Open Actions and select **Build Bbitcoin Android APK**.
4. Download `Bbitcoin-debug-apk` from the successful run's Artifacts section.

The workflow uses installed Gradle; it does not require a `gradlew` file.
